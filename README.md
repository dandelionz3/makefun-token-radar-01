A sealed-snapshot radar that ranks recorded pre-token protocols by a category-relative implied value model, with concrete farm plans and a separate live-market view. The static dashboard includes filters, per-protocol arithmetic, and adjustable display assumptions.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot>
```
